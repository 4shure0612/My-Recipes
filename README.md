# 내 책 레시피 검색 🍳

내 요리책 8권의 레시피 1,504개를 메뉴명 · 재료명으로 바로 찾는 휴대폰용 웹앱입니다.

- `index.html` — 앱 본체 (검색 · 하트로 찜하기 · 핑크 테마)
- `manifest.json`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` — 홈 화면에 추가할 때 쓰이는 앱 이름과 아이콘

휴대폰 브라우저(삼성 인터넷 · Chrome)에서 주소를 열고 **메뉴 → 현재 페이지 추가 / 홈 화면에 추가**를 누르면 예쁜 핑크 레시피 아이콘으로 홈 화면에 설치됩니다.
